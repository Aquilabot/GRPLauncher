# Contributing

Changes come in as pull requests against `master`; nobody outside the maintainers can push to this repository,
and `master` is a protected branch.

- One topic per pull request, with what it changes and how you tested it.
- Builds and releases are started by a maintainer (a version tag or a manual run). The build workflows do not run
  for pull requests, so a pull request is always read by a maintainer before any of its code is built.
- By sending a pull request you agree that your contribution is licensed under the Mozilla Public License 2.0,
  like the rest of the project.
- Security problems: write to the maintainer privately instead of opening an issue.
